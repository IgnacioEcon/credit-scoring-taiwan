# 💳 Score de Riesgo Crediticio - Taiwan Dataset

Este repositorio contiene un modelo de Machine Learning desarrollado para predecir la probabilidad de *default* en tarjetas de crédito a partir del dataset de clientes de Taiwán.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/drive/1ysITt1JmQfVOhEFTm09Esvxv_UH_BprW)

## 📌 Contenido del Repositorio
* `credit-scoring-taiwan.ipynb`: Notebook completo con el análisis exploratorio, preprocesamiento y entrenamiento del modelo Random Forest.
* `app.py`: Aplicación interactiva desarrollada en Streamlit para simular la evaluación del riesgo crediticio.
* `requirements.txt`: Dependencias necesarias para ejecutar la app.

## 🛠️ Herramientas
* **Lenguaje:** Python
* **Librerías:** Pandas, NumPy, Scikit-Learn, Streamlit
* **Modelo:** Random Forest Classifier
